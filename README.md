# Muromuro

This is the codebase of my past solo startup attempt.
While the startup itself didn't work out, this web app is functional and working as intended.

Muromuro was meant to be a Software Engineering Interview Platform that assesses candidates based on real-life development experience.
It asks candidates interview questions, and then assesses their responses.
Muromuro uses CodeMirror to format the code input of the candidates.
Muromuro connects to a Docker client to run the code input of the candidate in a Docker container, in a safe and isolated manner.
Muromuro also connects to a MySQL database to authenticate its admins and users.
