Detect Substrings

You are asked to implement a function that takes a String object as an input argument and returns a boolean. The string input can be long.

1. If the input string contains the word "foobar" then your function should return true.

2. If the input string contains any of the words "foobarbazbat", "foobarabcde", or "foobarxyzwt" then it should return false.

3. If the input string contains a combination of 1 and 2 above, then it should return true.

4. If the input string contains none of the above, then it should return false.

Please implement this function below. Please feel free to use any Java String library function in your implementation.
