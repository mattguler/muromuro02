Parse CSV

You are given a comma separated value (CSV) file string to parse. You are asked to parse this multi-line CSV string into a list of data structures.

Your input is a CSV string of multiple lines. The very first line contains the names of the fields represented in the subsequent lines. This particular CSV string represents a list of Accounts, and all the information related to those accounts.

Here is an example of a CSV file string, to be parsed by your program. (One thing you might notice here is that some values are missing. We'll come back to this.) 


    id, account_name, account_state, account_age, owner_first_name, owner_last_name
    15001, Foobar, , 5, Matt, Smith
    15002, Barbaz, ACTIVE, 2, , Brown
    15005, Bazbat, INACTIVE, 4, Joe, Miller
    ...

Your output is going to be a list of Account object instances. The Account is a Java record class which is defined as the following: 


    record Account(
        int id,
        String name,
        AccountState accountState,
        int accountAge,  // in years
        String ownerFirstName,
        String ownerLastName
    ) {}

The AccountState is a type of enum which is defined as the following: 


    enum AccountState {
        UNDEFINED,
        ACTIVE,
        INACTIVE
    }

Here are a few caveats and important points:

1. As you noticed, some of the values in the CSV string are missing. For string values, you should parse these entries as empty strings. For integer values, you should parse them as 0. For the empty AccountState entries in the CSV, you should parse them as UNDEFINED.

2. The order of the columns in the CSV file string could be randomly shuffled. This means the account_state and account_age could come before id and account_name, or owner_last_name could come before owner_first_name. The only way to determine the order of the cells is to parse the field names in the first line of the CSV.

3. The field name titles are not going to change. The same field titles are going to exist in all CSV file strings, even if the rest of the file is empty. It's just that the order of the field titles in the CSV could change, as mentioned in the point above.

4. None of the given field values are going to contain commas (","). The commas are only used as field separators and nothing else.

Please implement your solution below. You may use any Java String library function or anything from java.utils.* and java.utils.stream.* in your implementation.
