Long Running Functions

You are given a bunch of Black Box Processor objects that operate on a shared Account object. Each Black Box process() function takes a relatively long time to run. At the end of each run, the function updates the shared Account object's value. There are a number of Black Box processors running multiple times each in this given program. Naturally, the program is taking a long time to run. You are asked to make this program run quicker.

The shared Account object has a simple class description, with an account value, its setter, getter, and a class constructor: 


    public class Account {

        private int value;

        public Account(int value) {
            this.value = value;
        }

        public int getValue() {
            return value;
        }

        public void setValue(int value) {
            this.value = value;
        }
    }

The BlackBox class contains the process() function that operates on the shared Account object. The exact implementation details of the BlackBox class are not important. Here is what we really need to know about this class... 


    public class BlackBox {

        private final int id;       // Each BlackBox object has a unique ID.

        public BlackBox(int id) {
            this.id = id;
            // Other initializations take place here.
            ...
        }

        public boolean process(
                Account account,    // The shared account object reference.
                int code,           // Some integer code.
                // This method accepts a lambda to update the account:
                BiConsumer<Account, Integer> accountUpdater) {

            // This implementation here takes a long time to run.
            // It might be calling remote APIs, retrieving data from remote databases,
            // or just be waiting for something, who knows?
            // If anything goes wrong during this long process, this method returns
            // false.
            ...

            // Finally, determines the amount to update the account with.
            // The given code value and BlackBox object's own ID factor into
            // determining the exact update amount.
            int amount = ...

            // Updates the account using the lambda function, and returns true.
            accountUpdater.accept(account, amount);
            return true;
        }
    }

Each BlackBox object is created with a unique integer ID: 


    BlackBox blackBox = new BlackBox(id);

Its process() method takes in an Account object reference, an integer code, and a lambda function that describes how the account is meant to be updated. In this example, we update the account by adding the amount determined by the process() method to the account's current value. The process method also returns a boolean indicating the success of its run. 


    boolean result =
        blackBox.process(
            account,  // The shared Account object reference.
            code,     // An int.
            (acct, amount) -> acct.setValue(acct.getValue() + amount));  // A lambda.

A few other caveats to consider:

  • If any of the BlackBox processes fail (i.e. return false), the shared account might be left in an invalid state.
  • Feel free to define your own data structures and helper methods to solve this problem. But you cannot alter the definitions of the Account or BlackBox classes themselves.
