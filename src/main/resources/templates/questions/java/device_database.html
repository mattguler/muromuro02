Device Database

Setting

You are working in a data center team that is responsible for managing lots of devices such as servers, routers, switches, etc.

These devices are grouped by clusters. Each device belongs to a certain cluster. The clusters are named by three letters, such as "xyz", "ijk", etc.

The devices also have names themselves. Each device's name is prefixed by the 3 letter cluster name that the device belongs to, followed by a sequence of other letters or numbers. For example, you could have devices named "xyzabcde", "xyza1b2c", or "ijkasdfg". The first two devices in this example belong to the same cluster "xyz".

There is a Device Database that contains the information about these devices. The devices in the database are stored according to their clusters. Here is a representation of this storage organization:

Cluster Devices
xyz xyzabcde, xyza1b2c, ...
ijk ijkasdfg, ijklmnop, ...

The Device Database proxy object ddb has a ListDevices() function that accepts a cluster prefix string (e.g. "xyz") and returns the list of devices that are stored in the database belonging to that given cluster. Here is an example call:

String clusterName = "xyz";
List<String> results = ddb.ListDevices(clusterName);

This would return the list of device names for all the devices that are stored in the database for the cluster "xyz", such as: ["xyzabcde", "xyza1b2c", ...]

ddb.ListDevices() call results in a remote procedure call to the database. Therefore, it has some considerable latency. The returned list could be very long, and could be in any random order.

This has been the background setting for the question so far.
